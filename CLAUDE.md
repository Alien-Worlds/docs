# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Docusaurus 3 static documentation site for the Alien Worlds platform (Antelope/WAX smart contracts, DAO contracts, and the `aw-*` API tooling). Content is Markdown/MDX under `docs/`; there is no application code beyond a few React components used inside docs pages.

## Commands

pnpm, pinned via the `packageManager` field and corepack (`corepack enable`). Node version is pinned in `.nvmrc`. Only `pnpm-lock.yaml` is committed.

```
pnpm install        # install
pnpm start          # dev server with live reload
pnpm build          # static build into ./build
pnpm serve          # serve the built output
pnpm typecheck      # tsc
pnpm clear          # clear .docusaurus / .cache-loader caches
pnpm docusaurus download-remote-<name>   # re-fetch one remote-content plugin's docs
```

There is no test suite and no linter beyond `tsc`. `pnpm build` is the real check: `onBrokenLinks: 'throw'`, so a bad internal link fails the build.

Formatting: Prettier via `.prettierrc.yaml` — single quotes, 2 spaces, semicolons, es5 trailing commas.

## Architecture

**Docs are the site root.** `routeBasePath: '/'` in `docusaurus.config.ts`, so `docs/01- intro.md` (with `slug: /`, `id: overview`) is the homepage. `blog: false` — the `blog/` directory and `src/pages/_home.tsx` are unused leftovers from the template.

**Sidebar is fully autogenerated** from the `docs/` directory tree (`sidebars.js`, `{type: 'autogenerated', dirName: '.'}`). Ordering and labels therefore come from filenames: the `NN- ` numeric prefixes (`02- Antelope smart-contracts/`, `03- mining.md`) _are_ the sort order. Renaming or renumbering a file moves it in the nav and changes its URL — check for inbound links first.

Directories prefixed with `_` (`_03- API-services`, `_04- Solidity Smart Contracts`, `_05- Design System`) are excluded by Docusaurus — that underscore is how content is parked/hidden. Removing the underscore publishes it.

**Remote content.** `docs/03-API tools/**` is _generated_, not authored here. The `docusuarus_docs` array at the top of `docusaurus.config.ts` maps each `Alien-Worlds/<repo>` GitHub repo to an output directory under `docs/03-API tools/`, pulling README/tutorial Markdown from raw.githubusercontent (default branch `master` unless the entry sets an explicit `baseUrl`). `modifyContent` injects a `### [Source](...)` line and strips the License section. `noRuntimeDownloads: true` and `performCleanup: false` mean the fetched files are committed to this repo and are not refreshed on build — update them with the `download-remote-<name>` CLI command, and never hand-edit files under `docs/03-API tools/` (edits belong upstream and will be overwritten).

**Block explorer links.** Contract, action, and table headings in the smart-contract docs use `src/components/BlockExplorerLinks.tsx`, imported per-file inside the Markdown:

```mdx
import {
  BlockExplorerContractLinks,
  BlockExplorerActionLinks,
  BlockExplorerTableLinks,
} from '@site/src/components/BlockExplorerLinks';

## <BlockExplorerContractLinks contract="m.federation"/>

### <BlockExplorerActionLinks contract="m.federation" action="setparam" />
```

The components render the identifier as `<code>` plus themed icon links to wax.bloks.io and waxblock.io. Follow this pattern for new contract docs rather than hardcoding explorer URLs. Icons live in `static/img/`; light/dark variants go through `@theme/ThemedImage`.

**Mermaid** is enabled (`markdown.mermaid`, `@docusaurus/theme-mermaid`) — use ```mermaid fences directly. KaTeX deps (`remark-math`/`rehype-katex`) are installed but not currently wired into the preset.

## Conventions

- `.md` files containing JSX must still import their components explicitly; some files use `.mdx` where MDX features are heavier.
- Site-wide `url`/`baseUrl` in `docusaurus.config.ts` are still the Docusaurus template placeholders — do not treat them as the real deployment target.
